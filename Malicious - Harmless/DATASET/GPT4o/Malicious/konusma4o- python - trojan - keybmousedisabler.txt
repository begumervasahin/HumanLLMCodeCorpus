Using keyboard for Keyboard Control
The keyboard library is specifically designed for keyboard interactions.

Example Usage
python
Kodu kopyala
import keyboard

# Press and release a key
keyboard.press_and_release('shift+a')

Example Usage
python
Kodu kopyala
import mouse

# Move the mouse to a specific position
mouse.move(100, 100, absolute=True, duration=0.2)

mouse.click('left')

# Add a mouse event listener

    print(f'Button {event.button} clicked at {event.x}, {event.y}')
