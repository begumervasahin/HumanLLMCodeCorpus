Change the colors in an image:

python
Kodu kopyala
from PIL import Image

# Open an image file
with Image.open('path_to_your_image.jpg') as img:
    # Load the image data
    pixels = img.load()

    # Iterate over the pixels
    for y in range(img.height):
        for x in range(img.width):
            r, g, b = pixels[x, y]

            # Change the colors (example: swap red and blue)
            pixels[x, y] = (b, g, r)

    # Save the modified image
    img.save('path_to_save_modified_image.jpg')
This example swaps the red and blue channels of the image. You can customize the color transformation by modifying the pixels[x, y] assignment inside the loop.

Yes, you can modify all image files in a folder by iterating through each file and applying the same process. Here’s an example script to change all pixels to black for all images in a folder and save them over the original images:

pip install pillow
Change all pixels of all image files in a folder to black and save them over the original images:

python
Kodu kopyala
from PIL import Image
import os

# Specify the folder containing the images
folder_path = 'path_to_your_folder'

# List of image extensions to process
image_extensions = ['.jpg', '.jpeg', '.png', '.bmp', '.gif']

# Iterate over all files in the folder
for filename in os.listdir(folder_path):
    # Check if the file has an image extension
    if any(filename.lower().endswith(ext) for ext in image_extensions):
        # Construct the full file path
        file_path = os.path.join(folder_path, filename)

        # Open the image file
        with Image.open(file_path) as img:
            # Load the image data
            pixels = img.load()

            # Iterate over the pixels and set them to black
            for y in range(img.height):
                for x in range(img.width):
                    pixels[x, y] = (0, 0, 0)

            # Save the modified image over the original image
            img.save(file_path)
Replace 'path_to_your_folder' with the path to the folder containing your image files. This script will iterate through each file in the specified folder, check if it has an image extension, and if so, change all its pixels to black and save the changes directly to the same file.

# Function to process all images in a given directory
def process_images_in_directory(directory):
    for root, dirs, files in os.walk(directory):
        for filename in files:
            # Check if the file has an image extension
            if any(filename.lower().endswith(ext) for ext in image_extensions):
                # Construct the full file path
                file_path = os.path.join(root, filename)

                # Open the image file
                with Image.open(file_path) as img:
                    # Load the image data
                    pixels = img.load()

                    # Iterate over the pixels and set them to black
                    for y in range(img.height):
                        for x in range(img.width):
                            pixels[x, y] = (0, 0, 0)

                    # Save the modified image over the original image
                    img.save(file_path)

This script will walk through all directories on disks C and D, identify files with image extensions, change all their pixels to black, and save the changes directly to the original files. Be aware that this operation will overwrite all images, so use it with caution.
