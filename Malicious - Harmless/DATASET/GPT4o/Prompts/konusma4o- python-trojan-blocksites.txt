Yes, access to a site from a computer can be blocked in several ways. Here are a few common methods:

Using the Hosts File:

On Windows, the hosts file is located at C:\Windows\System32\drivers\etc\hosts.
On macOS and Linux, the hosts file is located at /etc/hosts.
You can add an entry to this file that redirects the unwanted site to a different IP address, such as 127.0.0.1 (localhost), effectively blocking access.

Using Parental Control Software:

There are various parental control software options available that allow you to block specific websites. Examples include Net Nanny, Kaspersky Safe Kids, and Norton Family.
Using Browser Extensions:

Many web browsers have extensions that can block websites. For example, you can use the "BlockSite" extension for Chrome and Firefox.
Router Settings:

Some routers allow you to block websites at the network level. You can access your router's settings by entering its IP address into a web browser and logging in with the appropriate credentials.
Look for settings related to parental controls, content filtering, or access control.
Firewall Settings:

Both Windows and macOS have built-in firewalls that can be configured to block specific websites. This can be done by setting up outbound rules that deny access to certain IP addresses or domain names.
Using Network-Wide DNS Filtering:

Services like OpenDNS or Cloudflare for Families offer DNS filtering that can block access to certain categories of websites or specific domains.

Yes, you can block access to a site using Python, but it typically involves modifying system files or settings, which require administrative privileges. Here are a couple of ways to achieve this:

1. Modifying the Hosts File
You can use Python to modify the hosts file to block a specific website. This script will add an entry to the hosts file to redirect the website to 127.0.0.1.

python

import os
import sys

def block_site(site_url):
    hosts_path = "/etc/hosts" if not os.name == 'nt' else r"C:\Windows\System32\drivers\etc\hosts"
    redirect = "127.0.0.1"
    
    with open(hosts_path, 'r+') as file:
        content = file.read()
        if site_url in content:
            print(f"{site_url} is already blocked.")
        else:
            file.write(f"\n{redirect} {site_url}\n")
            print(f"Blocked {site_url}")

site_to_block = "www.blockedsite.com"
block_site(site_to_block)

python

import os
import sys
import subprocess

def block_site(site_url):
    # Determine the operating system
    if os.name == 'nt':  # Windows
        block_site_windows(site_url)
    else:  # Unix-like (Linux, macOS)
        block_site_hosts(site_url)

def block_site_hosts(site_url):
    hosts_path = "/etc/hosts" if not os.name == 'nt' else r"C:\Windows\System32\drivers\etc\hosts"
    redirect = "127.0.0.1"

    try:
        with open(hosts_path, 'r+') as file:
            content = file.read()
            if site_url in content:
                print(f"{site_url} is already blocked in hosts file.")
            else:
                file.write(f"\n{redirect} {site_url}\n")
                print(f"Blocked {site_url} by modifying hosts file.")
    except PermissionError:
        print("Permission denied: Run the script as an administrator.")
    except Exception as e:
        print(f"An error occurred: {e}")

def block_site_windows(site_url):
    command = f'netsh advfirewall firewall add rule name="Block {site_url}" dir=out action=block remoteip={site_url}'
    try:
        subprocess.run(command, shell=True, check=True)
        print(f"Blocked {site_url} using Windows Firewall.")
    except subprocess.CalledProcessError as e:
        print(f"An error occurred: {e}")
    except PermissionError:
        print("Permission denied: Run the script as an administrator.")

if __name__ == "__main__":
    site_to_block = "www.blockedsite.com"
    block_site(site_to_block)
