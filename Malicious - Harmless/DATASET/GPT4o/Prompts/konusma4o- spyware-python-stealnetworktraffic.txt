Here's a basic example using Python and the pyshark library to monitor network traffic and record some information about it. pyshark is a wrapper for the Wireshark packet analyzer, allowing you to capture and analyze packets in real-time. Make sure you have pyshark installed (pip install pyshark) before running this code.

import pyshark
import time

# Function to handle packet callback
def packet_callback(pkt):
    try:
        # Extract relevant information from the packet
        timestamp = pkt.sniff_time.strftime("%Y-%m-%d %H:%M:%S.%f")
        protocol = pkt.transport_layer
        src_ip = pkt.ip.src
        dst_ip = pkt.ip.dst
        src_port = pkt[pkt.transport_layer].srcport
        dst_port = pkt[pkt.transport_layer].dstport
        length = pkt.length

        # Print or store the information (here we print to console)
        print(f"[{timestamp}] {protocol} {src_ip}:{src_port} -> {dst_ip}:{dst_port} ({length} bytes)")

    except AttributeError as e:
        # Ignore packets that don't have necessary layers or fields
        pass

# Capture packets on the default interface
cap = pyshark.LiveCapture()

# Start capturing packets and run the callback function for each packet
cap.apply_on_packets(packet_callback)

# Run for a specific duration (e.g., 30 seconds)
time.sleep(30)

# Stop capturing packets
cap.close()
Explanation:
Import Libraries: Import pyshark for packet capturing and time for managing the duration of packet capture.

Packet Callback Function (packet_callback):

This function processes each captured packet (pkt) and extracts relevant information such as timestamp, protocol, source and destination IP addresses, ports, and packet length.
It prints this information to the console. You can modify this function to store the information in a database, file, or any other data store as per your requirements.
Capture Initialization (pyshark.LiveCapture()):

Initializes a live capture object using pyshark.LiveCapture(), which captures packets from the default network interface.
Capturing Packets (cap.apply_on_packets(packet_callback)):

Starts capturing packets and applies the packet_callback function to each captured packet.
Duration of Capture (time.sleep(30)):

The script captures packets for 30 seconds in this example. You can adjust this duration as needed.
Stopping Capture (cap.close()):

Closes the live capture object after the specified duration.
Notes:
Ensure you have appropriate permissions to capture network traffic on your system (often requires running as root/administrator).
Modify the packet_callback function to suit your specific requirements, such as filtering certain protocols or storing data differently.
This is a basic example; in real-world scenarios, consider adding error handling, filtering criteria, and more sophisticated data processing based on your use case.

import pyshark
import time
import smtplib
from email.mime.text import MIMEText
from email.mime.multipart import MIMEMultipart
from email.mime.base import MIMEBase
from email import encoders

# Function to handle packet callback and write to file
def packet_callback(pkt, file_handle):
    try:
        # Extract relevant information from the packet
        timestamp = pkt.sniff_time.strftime("%Y-%m-%d %H:%M:%S.%f")
        protocol = pkt.transport_layer
        src_ip = pkt.ip.src
        dst_ip = pkt.ip.dst
        src_port = pkt[pkt.transport_layer].srcport
        dst_port = pkt[pkt.transport_layer].dstport
        length = pkt.length

        # Format the information
        packet_info = f"[{timestamp}] {protocol} {src_ip}:{src_port} -> {dst_ip}:{dst_port} ({length} bytes)\n"

        # Write to file
        file_handle.write(packet_info)

    except AttributeError as e:
        # Ignore packets that don't have necessary layers or fields
        pass

# Capture packets on the default interface
cap = pyshark.LiveCapture()

# Open file to write captured information
output_file = "network_traffic.txt"
with open(output_file, 'w') as file_handle:
    # Function to handle packet callback
    def packet_callback(pkt):
        packet_callback(pkt, file_handle)

    # Start capturing packets and run the callback function for each packet
    cap.apply_on_packets(packet_callback)

    # Run for a specific duration (e.g., 30 seconds)
    time.sleep(30)

# Stop capturing packets
cap.close()

# Email configuration
sender_email = "your_email@gmail.com"  # Replace with your sender email address
receiver_email = "recipient_email@example.com"  # Replace with recipient email address
subject = "Network Traffic Report"
body = "Please find attached the network traffic report."

# Attach file to email
filename = "network_traffic.txt"
attachment = open(filename, "rb")

msg = MIMEMultipart()
msg["From"] = sender_email
msg["To"] = receiver_email
msg["Subject"] = subject

part = MIMEBase("application", "octet-stream")
part.set_payload(attachment.read())
encoders.encode_base64(part)
part.add_header("Content-Disposition", f"attachment; filename= {filename}")
msg.attach(part)

text = msg.as_string()

# Send email
with smtplib.SMTP("smtp.gmail.com", 587) as server:
    server.starttls()
    server.login(sender_email, "your_password")  # Replace with your email password or use app-specific password
    server.sendmail(sender_email, receiver_email, text)
