Can we see the names of the applications installed on the computer with Python?
ChatGPT
Yes, you can see the names of the installed applications on your computer using Python. Below is a simple script that utilizes the pkg_resources module from the setuptools package to list all installed packages.

python
Kodu kopyala
import pkg_resources

installed_packages = pkg_resources.working_set
installed_packages_list = sorted(["%s==%s" % (i.key, i.version) for i in installed_packages])

for package in installed_packages_list:
    print(package)
You can run this script in your Python environment, and it will display the names and versions of all installed Python packages. If you need to see installed applications on your operating system (not just Python packages), the approach will differ based on the operating system you are using.

For Windows, you can use the following script to list installed applications:

python
Kodu kopyala
import subprocess

def get_installed_apps():
    cmd = 'powershell "Get-ItemProperty HKLM:\\Software\\Wow6432Node\\Microsoft\\Windows\\CurrentVersion\\Uninstall\\* | Select-Object DisplayName, DisplayVersion, Publisher, InstallDate"'
    proc = subprocess.Popen(cmd, shell=True, stdout=subprocess.PIPE)
    for line in proc.stdout:
        print(line.decode().strip())
