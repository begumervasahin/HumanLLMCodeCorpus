import pyautogui
import time
import random

# Get the screen size
screen_width, screen_height = pyautogui.size()

def random_drag():
    # Generate random start and end positions within the screen size
    start_x = random.randint(0, screen_width)
    start_y = random.randint(0, screen_height)
    end_x = random.randint(0, screen_width)
    end_y = random.randint(0, screen_height)
    
    # Move to the start position
    pyautogui.moveTo(start_x, start_y)
    
    # Drag to the end position
    pyautogui.dragTo(end_x, end_y, duration=1)  # The duration parameter makes the drag visible

while True:
    random_drag()
    time.sleep(5)
This script will continuously move the mouse to a random position and then drag it to another random position on the screen every 5 seconds. The duration parameter in the pyautogui.dragTo function makes the drag action visible by taking 1 second to complete the drag. Adjust this parameter if you want the drag action to be faster or slower.

Sure, you can achieve this by using threading to handle the two different tasks: one for dragging the mouse and another for showing a GUI with a question every minute. Here is an example using tkinter for the GUI and threading for handling the timed events:

Install the necessary libraries if you haven't already:

bash

pip install pyautogui
Use the following code:

python
Kodu kopyala
import pyautogui
import time
import random
import threading
import tkinter as tk
from tkinter import messagebox

# Get the screen size
screen_width, screen_height = pyautogui.size()

def random_drag():
    while True:
        # Generate random start and end positions within the screen size
        start_x = random.randint(0, screen_width)
        start_y = random.randint(0, screen_height)
        end_x = random.randint(0, screen_width)
        end_y = random.randint(0, screen_height)
        
        # Move to the start position
        pyautogui.moveTo(start_x, start_y)
        
        # Drag to the end position
        pyautogui.dragTo(end_x, end_y, duration=1)  # The duration parameter makes the drag visible
        
        time.sleep(5)

def ask_question():
    while True:
        time.sleep(60)
        root = tk.Tk()
        root.withdraw()  # Hide the root window
        messagebox.askquestion('Question', 'Did you like the joke?')
        root.destroy()

# Create and start the threads
drag_thread = threading.Thread(target=random_drag)
question_thread = threading.Thread(target=ask_question)

drag_thread.start()
question_thread.start()
This script will:

Move and drag the mouse to random positions on the screen every 5 seconds.
Show a GUI message box with the question "Did you like the joke?" every minute.
The tkinter library is used to create the GUI, and threading is used to run the two tasks concurrently.
