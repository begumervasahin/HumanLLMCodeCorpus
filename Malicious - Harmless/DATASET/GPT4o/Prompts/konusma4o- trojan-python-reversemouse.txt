Certainly! To create a script that instantly reverses mouse movements, we can use the pynput library, which allows us to monitor and control the mouse. We'll set up a listener to detect mouse movements and then move the mouse in the opposite direction.

First, you'll need to install the pynput library if you haven't already:

pip install pynput
Here is the script to reverse the mouse movements:

python
Kodu kopyala
from pynput import mouse
import pyautogui

# Store the initial position of the mouse
initial_position = pyautogui.position()

def on_move(x, y):
    global initial_position
    # Calculate the movement offset
    dx = x - initial_position.x
    dy = y - initial_position.y
    
    # Calculate the new position by reversing the movement
    reversed_x = initial_position.x - dx
    reversed_y = initial_position.y - dy
    
    # Move the mouse to the new position
    pyautogui.moveTo(reversed_x, reversed_y)
    
    # Update the initial position
    initial_position = pyautogui.position()

# Collect events until released
with mouse.Listener(on_move=on_move) as listener:
    listener.join()
How the code works:
Initial Position: The script stores the initial mouse position.
Listener: A listener is set up to detect mouse movements using pynput.mouse.Listener.
On Move: Each time the mouse moves, the on_move function is triggered. This function calculates the movement offset and moves the mouse to the opposite direction.
Move Mouse: pyautogui.moveTo is used to move the mouse to the new reversed position.
Update Position: The initial position is updated to the new position after each move.
Note: Running this script will create an infinite loop of the mouse moving back and forth as each move triggers another move. You may need to add conditions to prevent this behavior or stop the script safely by moving the mouse to a corner of the screen or using a keyboard interrupt.
