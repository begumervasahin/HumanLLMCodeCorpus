Yes, you can list the installed applications on a Windows computer using Python. This can be done by querying the Windows Management Instrumentation (WMI) using the wmic command and capturing the output.

Here’s a step-by-step example:

Using subprocess to List Installed Applications
python
Kodu kopyala
import subprocess

def list_installed_programs():
    try:
        # Run the wmic command to get the list of installed programs
        result = subprocess.run(['wmic', 'product', 'get', 'name'], stdout=subprocess.PIPE, text=True)
        
        # Split the result into lines and remove empty lines
        programs = [line.strip() for line in result.stdout.split('\n') if line.strip()]
        
        # The first line is the header, so we can skip it
        if programs:
            programs.pop(0)
        
        return programs
    except Exception as e:
        print(f"An error occurred: {e}")
        return []

# Example usage
installed_programs = list_installed_programs()
for program in installed_programs:
    print(program)
Explanation
Import subprocess: This module allows you to spawn new processes, connect to their input/output/error pipes, and obtain their return codes.
Run the wmic Command: The wmic product get name command retrieves the names of all installed products.
Capture and Process Output: The output is captured, split into lines, and cleaned up to remove any empty lines. The first line, which is a header, is skipped.
Return the List: The list of installed programs is returned and printed.
Additional Considerations
Administrative Privileges: Some installed applications might require administrative privileges to be listed, so it’s a good idea to run the script with administrative rights.
Filtering and Formatting: You can extend the script to filter the list or format the output as needed.

Certainly! Here’s a Python script that first lists all installed applications using wmic and then attempts to uninstall each one by one. This script should be run with caution and administrative privileges, as it will attempt to uninstall every listed application.

Warning
Running this script will attempt to uninstall all applications listed by wmic. This could render your system unstable or unusable. Make sure to run this only in a safe environment, like a virtual machine or a test system.

python

import subprocess
import os

def list_installed_programs():
    try:
        # Run the wmic command to get the list of installed programs
        result = subprocess.run(['wmic', 'product', 'get', 'name'], stdout=subprocess.PIPE, text=True)
        
        # Split the result into lines and remove empty lines
        programs = [line.strip() for line in result.stdout.split('\n') if line.strip()]
        
        # The first line is the header, so we can skip it
        if programs:
            programs.pop(0)
        
        return programs
    except Exception as e:
        print(f"An error occurred while listing programs: {e}")
        return []

def uninstall_program(program_name):
    try:
        # Construct the wmic command to uninstall the program by name
        command = f'wmic product where "name=\'{program_name}\'" call uninstall'
        
        # Execute the command
        os.system(command)
        print(f"Attempted to uninstall {program_name}")
    except Exception as e:
        print(f"An error occurred while uninstalling {program_name}: {e}")

def main():
    # List installed programs
    installed_programs = list_installed_programs()
    
    if not installed_programs:
        print("No programs found or an error occurred while listing programs.")
        return

    # Uninstall each program
    for program in installed_programs:
        print(f"Uninstalling {program}...")
        uninstall_program(program)

if __name__ == "__main__":
    main()
Explanation
List Installed Programs: The list_installed_programs function runs the wmic product get name command and processes its output to get a list of installed programs.
Uninstall Program: The uninstall_program function constructs and runs the wmic command to uninstall a program by its name.
Main Function: The main function lists all installed programs and then attempts to uninstall each one.
Important Notes
Run with Administrative Privileges: Ensure the script is executed with administrative privileges to successfully uninstall programs.
