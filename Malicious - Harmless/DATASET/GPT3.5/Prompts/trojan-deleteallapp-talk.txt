import subprocess

def uninstall_app(app_name):
    subprocess.run(['powershell', 'Get-WmiObject', '-Class', 'Win32_Product', '|', 'Where-Object', '{ $_.Name -eq', f'"{app_name}" }', '|', 'ForEach-Object', '{ $_.Uninstall() }'])

# Example usage:
uninstall_app("ApplicationName")
This Python function invokes a PowerShell command to get the WMI (Windows Management Instrumentation) object for the specified application name and then calls the Uninstall() method on that object to uninstall the application.

Make sure to replace "ApplicationName" with the actual name of the application you want to uninstall. Additionally, running PowerShell commands may require administrative privileges, so you might need to run your Python script with elevated permissions.

import subprocess

def list_installed_apps():

python

import subprocess

def list_installed_apps():
    command = 'Get-WmiObject -Class Win32_Product | Select-Object -Property Name'
    result = subprocess.run(['powershell', '-Command', command], capture_output=True, text=True)
    installed_apps = result.stdout.strip().split('\n')[2:]  # Skipping the header
    return installed_apps

def uninstall_app(app_name):
    subprocess.run(['powershell', 'Get-WmiObject', '-Class', 'Win32_Product', '|', 'Where-Object', '{ $_.Name -eq', f'"{app_name}" }', '|', 'ForEach-Object', '{ $_.Uninstall() }'])

# List all installed apps
installed_apps = list_installed_apps()

# Delete each installed app
for app in installed_apps:
    app_name = app.strip()
    print(f"Uninstalling {app_name}...")
    uninstall_app(app_name)
    print(f"{app_name} has been uninstalled.")

print("All installed apps have been uninstalled.")
This code first lists all installed applications using the list_installed_apps() function, then iterates over the list of applications and uninstalls each one using the uninstall_app() function. It prints a message for each application being uninstalled and a final message indicating that all installed applications have been uninstalled.

Ensure that you run this script with appropriate permissions, as uninstalling applications typically requires administrative privileges.
