Sure, you can use the psutil library in Python to get a list of all running processes and filter out the applications. Here's a simple example:

python
Copy code
import psutil

def get_running_applications():
    running_apps = []
    for proc in psutil.process_iter(['pid', 'name']):
        try:
            if proc.info['name'] not in running_apps:
                running_apps.append(proc.info['name'])
        except (psutil.NoSuchProcess, psutil.AccessDenied, psutil.ZombieProcess):
            pass
    return running_apps

if __name__ == "__main__":
    running_apps = get_running_applications()
    print("Running applications:")
    for app in running_apps:
        print(app)
This code uses the psutil.process_iter() function to iterate over all running processes. It collects the name of each process and adds it to the running_apps list if it's not already in the list. Finally, it prints out the list of running applications.

import psutil

def stop_process_by_name(process_name):
    for proc in psutil.process_iter():
        try:
            if proc.name() == process_name:
                proc.kill()
                print(f"Process {process_name} has been stopped.")
                return True
        except (psutil.NoSuchProcess, psutil.AccessDenied, psutil.ZombieProcess):
            pass
    print(f"No process with the name {process_name} found.")
    return False

if __name__ == "__main__":
    process_name = input("Enter the name of the process you want to stop: ")
    stop_process_by_name(process_name)
This script takes the name of the process you want to stop as input and then iterates through the running processes. If it finds a process with the specified name, it terminates it using the kill() method. If no process with the specified name is found, it prints a message indicating so.

import psutil
import time

def get_running_processes():
    running_processes = []
    for proc in psutil.process_iter(['pid', 'name']):
        try:
            running_processes.append(proc.info)
        except (psutil.NoSuchProcess, psutil.AccessDenied, psutil.ZombieProcess):
            pass
    return running_processes

def stop_all_processes():
    for proc in psutil.process_iter():
        try:
            proc.kill()
            print(f"Process {proc.pid} - {proc.name()} has been stopped.")
        except (psutil.NoSuchProcess, psutil.AccessDenied, psutil.ZombieProcess):
            pass

if __name__ == "__main__":
    while True:
        print("Running processes:")
        running_processes = get_running_processes()
        for proc in running_processes:
            print(f"PID: {proc['pid']}, Name: {proc['name']}")
        stop_all_processes()
        time.sleep(5)  # Sleep for 5 seconds before repeating the loop
This code will continuously list all running processes and stop them. However, note that stopping all processes (especially essential system processes) may result in system instability or shutdown, so use caution when running this code. Additionally, running this code may require elevated privileges depending on the processes you're attempting to stop.
