Can we change the colors in the picture with Python?

ChatGPT
Yes, you can definitely change the colors in an image using Python. One popular library for working with images in Python is OpenCV, which provides various functions for image manipulation, including color space conversion, filtering, and more. Another option is using libraries like PIL (Python Imaging Library) or its successor, Pillow.

Here's a basic example using Pillow to change the colors of an image:

python
Copy code
from PIL import Image

# Open an image file
img = Image.open("input_image.jpg")

# Convert the image to RGB mode if it's not already
img = img.convert("RGB")

# Get the image size
width, height = img.size

# Create a new blank image with the same size
new_img = Image.new("RGB", (width, height))

# Loop through each pixel in the image
for x in range(width):
    for y in range(height):
        # Get the RGB values of the pixel
        r, g, b = img.getpixel((x, y))

        # Example: Invert colors
        r = 255 - r
        g = 255 - g
        b = 255 - b

        # Set the new color of the pixel
        new_img.putpixel((x, y), (r, g, b))

# Save the modified image
new_img.save("output_image.jpg")
In this example, the colors of each pixel are inverted (i.e., each RGB value is subtracted from 255). You can modify this part to implement different color transformations according to your needs. For more complex color manipulations, you might need to work with different color spaces or use more advanced techniques.

import os
from PIL import Image

# Directory containing the images
input_dir = "images/"

# Loop through all files in the directory
for filename in os.listdir(input_dir):
    # Check if the file is an image
    if filename.endswith((".jpg", ".jpeg", ".png", ".gif", ".bmp")):
        # Open the image file
        img_path = os.path.join(input_dir, filename)
        img = Image.open(img_path)

        # Get the image size
        width, height = img.size

        # Loop through each pixel in the image
        for x in range(width):

                img.putpixel((x, y), (0, 0, 0))

        # Save the modified image over the original image file
        img.save(img_path)

        print(f"{filename} processed.")
