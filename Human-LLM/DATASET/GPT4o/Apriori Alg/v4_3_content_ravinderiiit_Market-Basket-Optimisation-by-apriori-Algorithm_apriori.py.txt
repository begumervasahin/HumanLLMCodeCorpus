# Apriori Algorithm for Market Basket Optimization

# Importing the necessary libraries
import numpy as np
import matplotlib.pyplot as plt
import pandas as pd
from apyori import apriori

# Data Preprocessing
dataset = pd.read_csv('Market_Basket_Optimisation.csv', header=None)

# Preparing the transactions data
transactions = []
for i in range(len(dataset)):
    transactions.append([str(dataset.values[i, j]) for j in range(dataset.shape[1])])

# Training the Apriori algorithm on the dataset
rules = apriori(transactions, min_support=0.003, min_confidence=0.2, min_lift=3, min_length=2)

# Visualizing the results
results = list(rules)

# Display the results
for result in results:
    print(result)
# Market Basket Optimization using Apriori Algorithm

This project uses the Apriori algorithm to analyze a dataset of mall transactions. The dataset contains records of 7500 transactions made by customers. The goal is to identify which items are frequently purchased together, helping the mall owner optimize the store layout and marketing strategies.

## Dataset
The dataset, `Market_Basket_Optimisation.csv`, includes 7500 transactions, with each transaction listing the items purchased by a customer.

## Approach
1. **Data Preprocessing**: Load and format the transaction data.
2. **Apriori Algorithm**: Apply the Apriori algorithm to find association rules with a minimum support of 0.003, minimum confidence of 0.2, and minimum lift of 3.
3. **Results Visualization**: Output the association rules found by the algorithm.

## Requirements
- numpy
- matplotlib
- pandas
- apyori

## Usage
1. Clone the repository.
2. Install the required libraries.
3. Run `apriori.py` to see the association rules extracted from the dataset.
